# Phase Context

This directory stores material context discovered during an approved milestone. Do not create a context record before its milestone begins.

Use one file per milestone or bounded workstream. Record only information whose omission could change scope, implementation, verification, recovery, or a future decision. Include observed facts, accepted decisions, constraints, evidence references, and unresolved questions. Do not copy requirements, architecture, ADRs, plans, journals, or status narration.

Suggested name:

```text
milestone-<NN>-<slug>.md
```

Context records are not approval records and cannot broaden an approved scope.
