# Engineering Toolkit `v0.2.1`

**Status:** Published on 2026-10-22.

`v0.2.1` adds deterministic project composition, strict offline template and
profile catalogs, and the first built-in project profile. It generates only the
provider-neutral engineering workspace layer; provider synchronization and
application-code generation remain outside this release.

## Added

- Strict offline readers for packaged catalogs, skill templates, and project
  profiles.
- Deterministic catalog, template, and profile inspection commands.
- Bounded `templates scaffold` authoring with absent-target enforcement,
  sibling staging, atomic publication, and rollback on failure.
- Typed template variables, deterministic in-memory rendering, and canonical
  skill validation.
- Read-only project inspection and evidence-based profile recommendations that
  never select a profile automatically.
- Deterministic composition plans for new projects and initialized workspaces.
- Approved `project create`, `project compose`, and `project recover`
  transactions with exact approval binding, durable journals, checkpoints,
  verification, and fail-closed recovery.
- The immutable `project-guide@0.1.0` canonical skill template and
  `go-service@0.1.0` project profile.

## Compatibility and security

- The source and release toolchain require Go 1.27.3.
- Built-in catalog assets retain LF line endings across supported platforms so
  their declared SHA-256 digests remain deterministic.
- Release binaries are built with CGO disabled.
- `SHA256SUMS` covers every binary, both installers, the release manifest, and
  the license.
- Installation verifies the selected binary checksum and reported version
  before publication, and replacement still requires explicit upgrade intent.

## Release verification

The stable release was built from commit
`38b7aab7b24253fee3e55ff1dbfae000dced4a4e` and passed:

- the complete Go test suite, `go vet`, and `govulncheck` with no reachable
  vulnerabilities;
- release packaging, manifest validation, and independent verification of all
  `SHA256SUMS` entries;
- native binary and installer transaction tests on Windows, Linux, and macOS;
- AMD64 and ARM64 coverage for all three operating systems; and
- a local Windows installation and explicit upgrade that preserved the binary
  digest and reported `engkit v0.2.1`.

The immutable source tag and 12 release assets are available in the
[`v0.2.1` GitHub Release](https://github.com/SummitExplorerJD/Engineering-Toolkit/releases/tag/v0.2.1).

## Known limitations

- Windows executables are not Authenticode-signed.
- macOS executables are not signed or notarized.
- Provider synchronization for Codex, Claude Code, and OpenCode is planned for
  a separately approved release.
- Production TUF activation, automatic updates, self-replacement, and
  package-manager distribution remain unavailable.
- Remote catalogs, arbitrary template imports, dependency installation, and
  execution of skill resources are not included.
