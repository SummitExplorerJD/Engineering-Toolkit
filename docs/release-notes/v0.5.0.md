# Engineering Toolkit `v0.5.0`

**Status:** Published on 2026-10-30 as the immutable latest stable release.

`v0.5.0` adds an optional concise human presentation for the existing read-only
doctor while preserving its canonical JSON automation contract.

## Added

- `engkit doctor --summary` and its exact short alias `engkit doctor -s`.
- Stable ASCII status labels: `[OK]`, `[WARN]`, `[ERROR]`, and `[N/A]`.
- An overall `OK` or `NEEDS ATTENTION` result with canonical status counts.
- Existing remediation text for non-pass findings through bounded `Next:`
  lines.
- Synthetic six-platform qualification for JSON compatibility, summary and
  help aliases, optional-state health, required-error health, and disclosure
  limits.

## Compatibility

- Unflagged `engkit doctor` continues to emit
  `engkit.doctor-result/v1alpha1` JSON.
- `-h` and `--help` remain help aliases and do not run diagnostic probes.
- Exit codes remain `0` for a healthy canonical result, `1` for required
  diagnostic errors, and `2` for invalid command input.
- Existing finding codes, deterministic ordering, summaries, remediation,
  evidence, health policy, and diagnostic probes are unchanged.
- Existing installations can use `install.ps1` or `install.sh` with explicit
  upgrade mode.

## Safety and output boundaries

- The human renderer consumes one completed canonical doctor result; it does
  not inspect the filesystem, SQLite, MCP, Ollama, providers, credentials, or
  the network independently.
- Concise output omits finding evidence and paths.
- Code, summary, and remediation fields normalize line controls and are limited
  to 512 UTF-8 bytes without splitting a code point.
- Output does not depend on terminal width, color, Unicode symbols, TTY state,
  locale, or environment variables.
- Remediation remains descriptive. Doctor does not install, repair, rebuild,
  recover, approve, or execute anything.

## Known limitations

- Windows executables are not Authenticode-signed.
- macOS executables are not signed or notarized.
- Production TUF activation, automatic updates, self-replacement, and
  package-manager distribution remain unavailable; this is a manual-update
  release.
- Context indexing remains explicit and local; it does not watch files or
  rebuild automatically.
- MCP remains read-only and stdio-only; remote MCP transport is unavailable.
- Human doctor output is currently English; labels are isolated in the CLI
  presentation adapter for later localization.
- Remote catalogs, marketplace installation, automatic dependency resolution,
  skill-resource execution, and automatic backup cleanup are not included.
