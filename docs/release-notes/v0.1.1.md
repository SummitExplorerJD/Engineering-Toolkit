# Engineering Toolkit `v0.1.1`

**Status:** Draft; not published.

`v0.1.1` is a compatibility-preserving installation and release-hardening
update. It does not add or remove `engkit` CLI commands.

## Added

- User-scoped PowerShell bootstrap installer for Windows.
- User-scoped POSIX shell bootstrap installer for Linux and macOS.
- Exact stable and `-rc.N` version selection.
- Automatic operating-system and architecture selection.
- Local release-directory installation mode for reviewed or offline assets.
- Additive installer metadata in `release-manifest.json`.
- Six-platform installation transaction tests in the release-candidate
  workflow.

## Safety

- SHA-256 verification is mandatory before a downloaded executable runs.
- Existing installations require an explicit upgrade option.
- Same-filesystem staging preserves the previous executable if publication
  fails.
- PATH modification is explicit and idempotent.
- Installers do not require administrator or root privileges.

## Known limitations

- GitHub HTTPS and repository controls authenticate network bootstrap assets;
  production TUF is not activated.
- Windows executables are not Authenticode-signed.
- macOS executables are not signed or notarized.
- Package-manager distribution, automatic updates, and self-replacement are not
  included.

## Verification before publication

- Run the release-candidate workflow for all six targets.
- Verify installer and executable hashes independently.
- Test a fresh installation and an explicit upgrade on Windows, Linux, and
  macOS.
- Replace this draft status with the final tag, commit, asset inventory, and
