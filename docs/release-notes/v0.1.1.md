# Engineering Toolkit `v0.1.1`

**Status:** Release candidate validated; stable release not published.

`v0.1.1` is a compatibility-preserving installation and release-hardening
update. It does not add or remove `engkit` CLI commands.

## Added

- User-scoped PowerShell bootstrap installer for Windows.
- User-scoped POSIX shell bootstrap installer for Linux and macOS.
- Exact stable and `-rc.N` version selection.
- Automatic operating-system and architecture selection.
- Local release-directory installation mode for reviewed or offline assets.
- Additive installer metadata in `release-manifest.json`.
- Six-platform installation transaction tests in the release-candidate
  workflow.

## Safety

- SHA-256 verification is mandatory before a downloaded executable runs.
- Existing installations require an explicit upgrade option.
- Same-filesystem staging preserves the previous executable if publication
  fails.
- PATH modification is explicit and idempotent.
- Installers do not require administrator or root privileges.

## Known limitations

- GitHub HTTPS and repository controls authenticate network bootstrap assets;
  production TUF is not activated.
- Windows executables are not Authenticode-signed.
- macOS executables are not signed or notarized.
- Package-manager distribution, automatic updates, and self-replacement are not
  included.

## Observed release-candidate verification

- `v0.1.1-rc.3` passed the release-candidate workflow on Windows, Linux, and
  macOS for AMD64 and ARM64.
- The downloaded candidate contained the six expected executables,
  `install.ps1`, `install.sh`, `LICENSE`, `release-manifest.json`, and
  `SHA256SUMS`.
- Every checksum and release-manifest size and digest matched the downloaded
  candidate contents.
- The packaged `install.sh` and `SHA256SUMS` used LF line endings, while the
  POSIX installer also accepted a reviewed CRLF checksum fixture.
- The installation transaction suite passed fresh-install, checksum-failure,
  wrong-version, replacement-refusal, rollback, explicit-upgrade,
  PATH-idempotence, and installed-version checks on all six runners.
- A local Windows AMD64 installation from the reviewed candidate directory
  completed without administrator privileges or a PATH modification and
  reported exactly `v0.1.1-rc.3`.

The stable `v0.1.1` artifacts must still be rebuilt from the approved release
commit, pass the same workflow, and be independently reviewed before the final
tag and immutable GitHub Release are published.
