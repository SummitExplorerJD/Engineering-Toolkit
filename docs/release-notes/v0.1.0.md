# Engineering Toolkit v0.1.0

**Status:** Draft; not published.

## Highlights

- Cross-platform Go CLI foundation for Windows, Linux, and macOS.
- Safe workspace inspection, initialization planning, approval binding, and
  recoverable `.engkit` publication.
- Optional rebuildable SQLite context index.
- Capability-based Codex, Claude Code, and OpenCode adapter inspection.
- Non-executable Spec Kit integration planning with official Spec Kit `v1.2.0`
  installed for Codex.
- Internal TUF verified-download core and disposable-key staging rehearsal.

## Available commands

```text
engkit version [--json]
engkit workspace inspect [--root PATH]
engkit workspace plan-init [--root PATH]
engkit workspace init [--root PATH] --approve PLAN_ID
engkit context rebuild [--root PATH]
engkit context status [--root PATH]
engkit context search [--root PATH] QUERY
engkit adapters list
engkit adapters inspect [--root PATH] --provider PROVIDER
engkit speckit plan [--root PATH] --integration PROVIDER --version RELEASE_TAG
```

## Important limitations

- Update check/download commands are not public yet.
- No installer or automatic executable replacement is included.
- No production TUF root or repository endpoint is configured.
- Spec Kit plans are deliberately non-executable.
- Windows signing and macOS signing/notarization are not yet configured.
- Native smoke-test evidence for every OS/architecture remains a release gate.

## Integrity

The final release will publish `SHA256SUMS` and a versioned release manifest.
Verify the checksum before running a downloaded executable. Final hashes are
created only from the approved release commit and are not included in this
draft.
